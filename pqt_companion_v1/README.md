# PQT Companion V1

Discord Server Companion V1: Companion theo server, XP/level, daily quests, badges, profile, progress và JSON database nhẹ.

## Yêu cầu
Node.js 20+

## Cài đặt
1. `npm install`
2. Copy `.env.example` thành `.env` và điền token, Application ID, Test Server ID.
3. `npm run deploy`
4. `npm start`

**Không gửi Bot Token cho người khác.**

## Commands
`/companion` — xem Companion server
`/profile [user]` — xem profile
`/quest` — xem daily quests
`/badges` — xem badges
`/progress` — xem tiến trình server
`/daily` — điểm danh nhận XP

V1 ưu tiên nền tảng. Evolution, server quest, memory và dashboard để V2.
