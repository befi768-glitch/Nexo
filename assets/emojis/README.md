# Nexo Branded Image Emoji Pack

Nexo 2.7.1 uses a single visual language for its bot emoji: dark glass cores, cyan/violet orbital rims, soft bloom, crisp white linework, and small accent sparks.

Each logical state has its own 128×128 transparent PNG and editable SVG master. The provisioner uploads them as `nexo_<name>` so Nexo does not collide with unrelated server emoji.

The pack covers progression, profile, quest, economy, status, server milestones, memory and Nexo personality states. Unicode is used only as a graceful fallback when an image emoji cannot be provisioned.
