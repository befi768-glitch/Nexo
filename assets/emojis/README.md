# Nexo image emoji pack

These transparent 128px assets use a shared “soft orbital” language: a dark
violet core, a cyan-to-lilac rim, and one recognizable symbol per action.
Use the SVG files as editable masters, or upload the matching files in
`assets/emojis/png/` as server emojis in Discord. The filename maps to the environment
variable in `.env.example`, for example `spark.svg` → `NEXO_EMOJI_SPARK_ID`.

Discord custom emoji markup is generated by `src/emoji.js`, so all commands
automatically show the image version once an ID is configured.
